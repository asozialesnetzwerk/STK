Windows compilation:
-------------------------------------------------------------------------------------------------------------------

1) Download LAZARUS 0.95 from http://snapshots.lazarus.shikami.org/lazarus/

	Win x64: http://snapshots.lazarus.shikami.org/lazarus/downloads/Lazarus-0.9.25-fpc-2.2.1-20080524-win64.exe
	Win x32: http://snapshots.lazarus.shikami.org/lazarus/downloads/Lazarus-0.9.25-fpc-2.2.1-20080524-win32.exe

2) Install.

3) Open file STKed.lpi

4) compile.



Linux compilation:
-------------------------------------------------------------------------------------------------------------------

1) Download LAZARUS 0.95, fpc and fpc-src from http://snapshots.lazarus.shikami.org/lazarus/

2) Install.

3) Open file STKed.lpi

4) Compiler Options - change LCL to gtk2  

5) compile.	

Under Ubuntu 8.04 use Synaptic :)
